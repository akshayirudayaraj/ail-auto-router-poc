# examples/

A few committed sample lines of each dataset so you can see the schema without
running the pipeline. These are generated by `make all` into `data/` (which is
git-ignored); here we keep small excerpts.

- `raw_logs.sample.jsonl` — Pillar 1a raw session log. Note the `_true_*` hidden
  ground-truth fields (graders only; stripped before extraction). A clean
  weak-local → user-switch → frontier-success narrative usually appears in the
  first session.
- `pointwise.sample.jsonl` — structured pointwise rows (implicit- and
  judge-sourced). `embedding` is truncated here only in your head view; the real
  file carries the full 768-d vector.
- `pairwise.sample.jsonl` — derived pairwise preferences (escalation + NN).
- `gold.sample.jsonl` — dual-arm gold rows: both `outcome_local` and
  `outcome_frontier` known, with per-arm cost. `executable:false` marks the seam
  for real unit-test outcomes.

See the schema definitions in `internal/schema` and the field-by-field
production-logging requirements in the top-level README.
